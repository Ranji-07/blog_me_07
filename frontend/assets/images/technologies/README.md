# Technology logo assets

The SVG marks in this directory are stored locally for the mobile technology
showcase. They were retrieved from the [Devicon project](https://devicon.dev/)
at tag `v2.16.0`, except `django.svg`, which was retrieved from
[Simple Icons](https://simpleicons.org/).

The AWS service icons (`ec2.svg`, `s3.svg`, `iam.svg`, `vpc.svg`, `ecr.svg`,
`eks.svg`, `cloudwatch.svg`, and `codepipeline.svg`) use the AWS Architecture
Icons asset set, obtained from the
[aws-architecture-icons mirror](https://github.com/icacho-dev/aws-architecture-icons).
