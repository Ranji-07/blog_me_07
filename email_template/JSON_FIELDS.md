# JSON keys and current values

These are examples from `backend/content/*.json`, generated by `python email_template/generate_json_fields.py`.
Edit the content files in `backend/content/` directly. `[]` in a key means each array item has that field.
The list shows the first value found for repeated fields; check each array item before publishing.
For a local image, use a served `/images/filename.png` path only after placing the file in `backend/app/uploaded_images/`; content publishing is currently manual.
Project `github` and `live_demo` must be HTTPS URLs or empty strings. No JSON/image upload or email approval endpoint is active.
The list describes current values, not schema validity. `contact.availability` accepts `freelance`, `fulltime`, `internship`, and `response_time`; the Landing availability state is `about.availability` (`open`, `freelance`, or `unavailable`).
